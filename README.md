## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/poojagajendran/GRAPHIC_DESIGNER_PROTFOLIO.git
```

Navigate into the project

```bash
cd GRAPHIC_DESIGNER_PROTFOLIO
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open your browser

```text
http://localhost:5173
```
